### 🔎 Total-Recon

<p align="center">
  <a href="https://github.com/singhdavinderdeosi/Total-Recon">
    <img src="https://github-readme-stats.vercel.app/api/pin/?username=singhdavinderdeosi&repo=Total-Recon&theme=nord&title_color=7dd3fc&text_color=7dd3fc&icon_color=7dd3fc&border_color=7dd3fc" alt="Total-Recon repo card" />
  </a>
</p>

A Tkinter-based reconnaissance toolkit for cybersecurity professionals and penetration testers, with five modules: HTTP status checker, bounded subdomain scanner, bounded directory scanner, Google dork URL generator and JWT secret wordlist checker.

| Layer | Technology |
| :--- | :--- |
| Language | Python 3.10 |
| GUI | Tkinter |
| Networking | Requests |
| JWT checks | PyJWT |
| Concurrency | Standard-library worker pool (bounded scans, background threads) |
| Testing & CI | pytest, GitHub Actions on Windows and macOS |

🔗 [Code](https://github.com/singhdavinderdeosi/Total-Recon)

> *Use only on systems and domains you own or are authorized to assess.*

### 🔐 SecureFileX

<p align="center">

A Django-based secure file management platform with file encryption and decryption, image steganography, AI assistance, activity logs and secure user authentication, built with a privacy-first approach.

| :--- | :--- |
